# Mobile Quantum Simulator

Projektarbeit – FH JOANNEUM, Mobile Software Development
Winter Semester 2026/27

## Objective
Design, implement, and evaluate a lightweight quantum circuit
simulator running locally on a mobile iOS device.

## Planned Approach
- Research existing quantum simulation implementations
- Develop or adapt a lightweight C++ simulation backend
- Integrate the backend into an iOS application
- Validate correctness against reference results
- Benchmark execution time and memory usage

## Potential Extension
Explore Pauli Correlation Encoding (PCE) as a possible
application and research direction for the Bachelorarbeit.
